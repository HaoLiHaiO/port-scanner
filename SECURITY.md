# Security and responsible use

This repository is a learning project for port scanning. Run scans only against systems you own or are explicitly authorised to test.

- Prefer a local lab or other isolated test environment.
- Avoid scanning production networks without a defined scope and permission.
- Do not treat an open port as proof of a vulnerability.
- Verify findings before reporting them and avoid publishing sensitive service details.

If you discover a security issue in this repository, contact the maintainer privately rather than posting exploitation details in a public issue.
